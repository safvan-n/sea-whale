# Sea Whale Transport - Flutter Mobile & Web App

A luxury seafood & fresh meats cold-chain logistics e-commerce application built with **Flutter**, **Provider**, and **Google Fonts (Outfit & Inter)**.

## 📱 Features

1. **Luxury Ocean Aesthetic**: Deep midnight navy, ocean teal, and neon cyan palette with glassmorphism cards and smooth responsive animations.
2. **Dynamic Storefront**: Full product catalogue (Salmon, Tiger Prawns, Mud Crabs, Biryani Mutton, Wagyu Ribeye, Calamari, Organic Farm Eggs, etc.).
3. **Weight-based Pricing**: Dynamic real-time price updates for custom weights (250g, 500g, 1kg, etc.).
4. **Interactive Shopping Cart**:
   - Weight & quantity controls
   - Promo code coupons (`OCEANFRESH` for ₹150 OFF, `SEAWALE20` for 20% OFF)
   - Cold-chain nitrogen packaging fee and delivery fee calculation
   - Instant address switcher & checkout payment gateway sheet
5. **Live Cold-Chain Telemetry Tracker**:
   - Real-time GPS container tracking simulation
   - Live temperature fluctuation sensor (0-2°C optimal range)
   - Transit milestone status timeline
6. **Harbour Pre-Order Module**: Reserve rare catches directly from fishing boats before they dock at harbor.
7. **B2B Bulk Wholesale Quotation**: Dynamic contract cost calculator for restaurants, luxury hotels, and supermarket chains.

## 🚀 How to Run the App

Navigate to the Flutter directory:
```bash
cd sea_whale_app
```

### Run on Chrome (Web)
```bash
flutter run -d chrome
```

### Run on Windows Desktop
```bash
flutter run -d windows
```

### Run on Android Device / Emulator
```bash
flutter run -d android
```

### Build Android APK
```bash
flutter build apk --release
```
